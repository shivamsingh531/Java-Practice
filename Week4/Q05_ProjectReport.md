# Java Mini Project Report

## Project Title

Library Management System

## Objective

The objective of this project is to create a simple Library
Management System using Java OOP concepts, Collections and
File Handling.

## Concepts Used

- Classes and Objects
- Constructors
- Methods
- ArrayList
- File Handling
- Exception Handling

## Project Logic

The system uses a Book class to store book details such as
title and author.

An ArrayList is used to store multiple books.

The addBook() method adds new books to the library.

The displayBooks() method displays all available books.

The saveToFile() method stores the book details in a text file
named library.txt.

## Working

1. Create a Book object.
2. Store book details.
3. Add the book to ArrayList.
4. Display all books.
5. Save book information into a text file.

## Conclusion

This project demonstrates the basic implementation of a
Library Management System using Java. It combines OOP,
Collections and File Handling concepts into a single project.
